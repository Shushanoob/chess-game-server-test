# Шахматная школа — GitHub Pages test

Это тестовая веб-версия текущей игры для проверки живых онлайн-партий до публикации в Яндекс Играх.

## Онлайн
Клиент уже настроен на:
`wss://chess-game-servers.onrender.com`

Поэтому сервер отдельно запускать не нужно. Откройте сайт на двух разных устройствах, на одном создайте комнату, на втором войдите по коду.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий.
2. Загрузите всё содержимое этой папки в корень репозитория.
3. В GitHub откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните и дождитесь публикации.

`index.html` уже находится в корне и использует относительные пути, поэтому проект подходит для GitHub Pages.

## Ограничения тестовой версии
- Яндекс SDK не подключается.
- Яндекс Лидерборд в этой версии не тестируется.
- Профиль и Elo работают локально через localStorage.
- Онлайн-игра работает через внешний WebSocket-сервер Render.

После проверки онлайн эту же игру можно вернуть в сборку для Яндекс Игр и подключить SDK/Лидерборд.
